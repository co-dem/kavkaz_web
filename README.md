# KAVKAZ — лендинг студии танцев

## Запуск
Откройте `index.html` в браузере. Для локальной разработки можно использовать VS Code + Live Server.

## Где заменить фотографии
Добавьте изображения в папку `assets/`, затем раскомментируйте и заполните `photoMap` в `script.js`. Ключи: `hero`, `students`, `teacher1`, `teacher2`, `teacher3`, `ensemble`, `show1`, `show2`, `gallery1` и другие `gallery`-слоты. Для hero можно также задать `background-image` у `.hero-bg` в `styles.css`.

## Перед публикацией
- Заменить все ссылки Instagram/TikTok на реальные аккаунты студии, ансамбля и шоу-группы.
- Подставить подтверждённые имена/биографии преподавателей и реальные отзывы.
- Проверить расписание, цены, возрастные ограничения и контакты.
- Указать домен в canonical и Open Graph URL, настроить sitemap.xml и robots.txt.

## Включено
Адаптивная мобильная версия, раскрывающееся мобильное меню, анимированные появления блоков, движение hero-фона, карточки преподавателей с диалогом, FAQ, фильтры галереи, свайп/горизонтальная прокрутка, карусель отзывов, SEO meta description и Open Graph.

## Последние улучшения
- Карточка преподавателя открывает диалог с мини-фотографией, именем и описанием.
- Бургер-меню на мобильных устройствах открывается поверх всего экрана с полупрозрачным размытым фоном, анимацией пунктов, блокировкой прокрутки страницы и закрытием по Esc/выбору ссылки.


## Отдельное фото в окне преподавателя

Для каждого преподавателя можно использовать две разные фотографии:
- `teacher-1.jpg` — портрет в карточке на странице;
- `teacher-1-detail.jpg` — другая фотография, которая появляется после нажатия на карточку.

Положите дополнительные фотографии в папку `assets` рядом с `index.html`:
- `assets/teacher-1-detail.jpg`
- `assets/teacher-2-detail.jpg`
- `assets/teacher-3-detail.jpg`

Пути к фотографиям для открытого окна уже добавлены в `script.js`. Для фотографий в самих карточках используйте ключи `teacher1`, `teacher2`, `teacher3` в объекте `photoMap`.
